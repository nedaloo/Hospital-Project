# 🏥 Hospital Management System

A Java Desktop application designed to manage core hospital workflows, including patient records, doctor profiles, and system user authentication.

## 🛠️ Tech Stack
* **Language:** Java (JDK)
* **GUI Framework:** Java Swing & AWT (`JCalendar` for date picking)
* **Database Connectivity:** JDBC (`PreparedStatement`, `DBConnection` utility)
* **Database:** SQL Server / MySQL (`hospital` database with `users`, `doc`, and `paiten` tables)

## ✨ Key Features
* **User Authentication:** Secure login system to manage staff access.
* **Patient Management:** Add, update, and track patient details and admission dates.
* **Doctor Management:** Maintain doctor records, specializations, and schedules.
* **Clean Architecture:** Externalized database configuration (`config.properties`) and resource-safe JDBC queries.
